# Session count guide

Choose the number of study sessions from the total budget:

| Total budget | Sessions |
|---|---|
| Under 45 minutes | 1 |
| 45–119 minutes | 2 |
| 120–239 minutes | 3 |
| 240 minutes or more | 4 |

- Prefer one focused topic per session over mixed topics.
- When the budget allows three or more sessions, make the last one a review or
  practice session, for example "Python: review exercises".
- Never request more sessions than the budget has minutes.
